# Industrial KPI Dashboard

Mini dashboard simulant une ligne de production industrielle.

## KPIs suivis :
- Production totale
- Taux de défaut
- Temps d'arrêt (downtime)

## Tech :
- Python
- Pandas
- Streamlit

## Objectif :
Démontrer la capacité à analyser des données industrielles et générer des indicateurs de performance (KPI).
